## Conventions fixed by this plan (binding)

- **Fin direction:** a fin traverses its edge from `start` to `end`; `forward = true` means edge's (bound_0 -> bound_1). The end-vertex of a fin is the vertex between it and `next` in the loop.
- **Face sense:** the surface normal (or implied plane normal) points out of the Front side. `front_region` is the region whose shell uses (face, Front).
- **Shells:** a shell is a connected set of oriented face-sides plus wire edges plus at most one acorn vertex, owned by exactly one region. A closed manifold face set therefore appears as TWO shells (one per side, in the two regions it separates). A sheet face has both its sides in the SAME shell (same region).
- **Closed edges:** an edge may be closed (both bounds the same seam vertex). Vertex-free ring edges are NOT supported in M3 (CW-complex counting stays simple); every closed edge has a seam vertex.
- **Region solidity rule:** a region created inside parent region P has `solid = !P.solid`. The infinite region is void and indestructible.
- **Euler-Poincare check (manifold complexes):** `V - E + F = 2*(S_closed - G) + R` where S_closed = closed-surface count (= non-infinite region count for manifold bodies), G = total genus (stored per shell pair, incremented only by KFMRH), R = inner ring count. Asserted by `validate()`; debug builds run validate after every public operation.

```rust
//! Generational typed arena. Slots are transient memory addresses,
//! NEVER identity (EntityId is identity). Iteration over an arena is
//! for internal traversal only; anything that influences output
//! iterates in EntityId order via Body::ids.

use core::marker::PhantomData;

pub struct Key<T> {
    index: u32,
    generation: u32,
    _marker: PhantomData<fn() -> T>,
}
// Manual impls so T need not be Clone/Eq: Copy, Clone, PartialEq, Eq,
// PartialOrd, Ord, Hash, Debug (derive with PhantomData is fine via
// manual impl blocks; write them out).

enum Slot<T> {
    Occupied { generation: u32, value: T },
    Free { generation: u32 },
}

pub struct Arena<T> {
    slots: Vec<Slot<T>>,
    free: Vec<u32>, // LIFO, deterministic
    len: usize,
}

impl<T> Arena<T> {
    pub fn new() -> Self { Self { slots: Vec::new(), free: Vec::new(), len: 0 } }
    pub fn len(&self) -> usize { self.len }
    pub fn is_empty(&self) -> bool { self.len == 0 }

    pub fn insert(&mut self, value: T) -> Key<T> {
        self.len += 1;
        if let Some(i) = self.free.pop() {
            let generation = match self.slots[i as usize] {
                Slot::Free { generation } => generation + 1,
                Slot::Occupied { .. } => unreachable!("free list corrupt"),
            };
            self.slots[i as usize] = Slot::Occupied { generation, value };
            Key { index: i, generation, _marker: PhantomData }
        } else {
            let i = self.slots.len() as u32;
            self.slots.push(Slot::Occupied { generation: 0, value });
            Key { index: i, generation: 0, _marker: PhantomData }
        }
    }

    pub fn get(&self, k: Key<T>) -> Option<&T> { /* generation check */ }
    pub fn get_mut(&mut self, k: Key<T>) -> Option<&mut T> { /* ditto */ }
    pub fn remove(&mut self, k: Key<T>) -> Option<T> { /* mark Free, push free list */ }
    /// Internal traversal only; order is allocation-dependent.
    pub fn iter(&self) -> impl Iterator<Item = (Key<T>, &T)> { /* occupied slots */ }
}
```

### Task 3: validation and topology hash

**Files:** validate.rs

- [ ] **Step 1: structural checks** (`Body::validate() -> Result<(), Vec<ValidationError>>`):
  1. Every key reference resolves (no stale keys); ids map is a bijection onto live entities.
  2. Fin rings closed: from any loop fin, `next` returns in finite steps covering prev-consistency (`fin.next.prev == fin`).
  3. Radial cycles: every fin appears exactly once in its edge's radial vec; every radial member's `edge` back-reference matches.
  4. Loop ownership: every fin's `owner` loop contains it (reachable from loop entry); `loops[0]` of each face has kind Outer; vertex loops have `fin: None, vertex: Some`.
  5. Shell/region: every (face, side) pair appears in exactly one shell across the body; `front_region`/`back_region` match the owning shells' regions; every shell's region lists it; exactly one infinite region; infinite region is void.
  6. Boundary-of-boundary (d-of-d = 0 oracle): over the incidence structure mod 2, the boundary of every face (sum of its fins' edges) has zero vertex boundary: for each loop, each vertex is met an even number of times by loop fins (start/end pairing). Catches dangling fin surgery errors the Euler formula misses.
  7. Euler-Poincare for the manifold sub-complex (all edges with radial count == 2 and faces over them): `V - E + F = 2*(S_closed - G) + R` with S_closed = non-infinite region count contribution and G summed from shell genus (divided by the shell-pair convention; specified precisely in code comments). Skipped for bodies containing non-manifold edges (radial > 2), where checks 1-6 plus d-of-d govern (gate section 2.3).

Test: hash invariant under arena slot reuse (build, delete, rebuild differently, compare equal bodies' hashes).

```rust
pub struct MvfsOut { pub vertex: VertexKey, pub face: FaceKey, pub interior: RegionKey,
                     pub shell_outer: ShellKey, pub shell_inner: ShellKey, pub report: OpReport }

/// Seed a minimal closed body in `region`: vertex v, face f whose
/// single loop is the vertex loop at v, shells for both sides, and a
/// new interior region with solidity !region.solid. Front of f faces
/// `region` (outward), Back faces the interior.
pub fn mvfs(&mut self, region: RegionKey, p: Vec3) -> Result<MvfsOut, TopoError>;

/// Destroy a minimal body (face must have exactly one loop and that
/// loop must be a vertex loop; both shells must contain only this
/// face). Merges the interior region away. Strict inverse of mvfs.
pub fn kvfs(&mut self, face: FaceKey) -> Result<OpReport, TopoError>;

pub enum MevSite {
    /// Upgrade a vertex loop: the new edge runs from the loop's vertex
    /// to the new vertex; the loop becomes a 2-fin ring (out and back).
    VertexLoop(LoopKey),
    /// Insert a spur after `fin`: new edge from end-vertex(fin) to the
    /// new vertex; loop order becomes ... fin, fin_out, fin_back, fin.next ...
    AfterFin(FinKey),
}
pub struct MevOut { pub edge: EdgeKey, pub vertex: VertexKey, pub report: OpReport }
pub fn mev(&mut self, site: MevSite, p: Vec3) -> Result<MevOut, TopoError>;

/// Kill a spur edge: its far vertex must have exactly the two fins of
/// this edge incident (valence 1 geometrically). Loop shrinks; if the
/// loop drops to zero fins it reverts to a vertex loop at the near
/// vertex. Strict inverse of mev.
pub fn kev(&mut self, edge: EdgeKey) -> Result<OpReport, TopoError>;
```
